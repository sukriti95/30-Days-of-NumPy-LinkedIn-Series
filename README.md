# 30 Days of NumPy – From Python Fundamentals to Data Applications

Welcome to my 30 Days of NumPy learning journey!

This repository documents my hands-on exploration of NumPy, one of the most important Python libraries for numerical computing and data processing.

The objective is to strengthen my Python skills and understand how NumPy can be applied to real-world Data Analytics and Data Engineering problems.

## What I'm Learning

- Creating and manipulating NumPy arrays
- Array indexing, slicing and reshaping
- Mathematical and statistical operations
- Broadcasting and vectorization
- Data filtering and transformation
- Handling missing and numerical values
- Performance optimization
- Integrating NumPy with Pandas
- Solving practical data problems
